# ルーペ (Magnifier)

カメラで小さな文字を大きく見る、ブラウザだけのルーペです。薬の箱、ラベル、メニューに。無料・広告なし・ログイン不要。最初の読み込みのあとはオフラインで使えます。

- ズーム（カメラのズームが使えればそれを、なければ画面で拡大）
- 止める／もどす：いまの画面を止めて、ゆっくり読む（指でずらせます）
- 見え方：ふつう／くっきり／白黒反転
- ライト（対応している端末だけ）

映像はどこにも送りません。

**English:** A camera magnifier for small print. Zoom, freeze the frame to read it steadily, high-contrast view, and the light when the phone supports it. Free, no ads, no login, works offline. Nothing leaves your device.

Live: https://gutsmcd-cmd.github.io/loupe/
